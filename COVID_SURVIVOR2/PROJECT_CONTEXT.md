# Contexto do Projeto — COVID SURVIVOR

- **Nome:** COVID SURVIVOR
- **Engine:** Unity 6.5.8f1 (6000.5.8f1)
- **Template:** Universal 2D (URP)
- **Linguagem:** C#
- **Plataforma inicial:** PC
- **Gênero:** sobrevivência em arena 2D, com visão top-down
- **Protagonista:** médico com roupa branca
- **Inimigos:** criaturas estilizadas inspiradas no coronavírus
- **Jogabilidade:** movimentação pelo cenário e ataques automáticos
- **Habilidades planejadas:** Vacina Mágica, Álcool 70%, Anticorpos e Supervacina
- **Objetivo atual:** sobrevivência infinita, sem vitória: movimentação, inimigos, combate elemental automático, vida, spawn progressivo, XP e upgrades, cronômetro, pontuação e derrota com reinício
- **Desenvolvimento acadêmico:** os integrantes precisam compreender e conseguir explicar todo o código ao professor
